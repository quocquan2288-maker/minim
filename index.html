Hướng Dẫn Triển Khai Lên GitHub Pages

Hoạt động trên Điện thoại & PC

1. Tạo một Repository Public mới trên GitHub (ví dụ: flow-video-sync).

2. Tạo file mới tên là index.html, dán toàn bộ mã nguồn này vào và bấm Commit changes.

3. Vào mục Settings → Pages → Branch: main → Save. Đường dẫn web https://<tên-github>.github.io/flow-video-sync/ sẽ hoạt động ngay sau 30 giây!
